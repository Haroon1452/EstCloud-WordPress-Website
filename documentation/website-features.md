# EstCloud OU – Website Features and Functionality

## 1. Overview

The EstCloud website is a corporate IT services platform presenting the company's managed cloud, cybersecurity, Microsoft 365, and IT consulting offerings.

The website uses WordPress and Elementor to organize its content into dedicated pages and service sections.

- Customer engagement process.
- Consultation and contact calls to action.
